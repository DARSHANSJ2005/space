A NOTE ON PRIVACY

Private, not magic.

Messages are encrypted in your browser and sent directly between devices. SPACE's temporary server only helps the devices find each other; it does not receive message text.

No service can promise perfect security. Your SPACE code is also the secret needed to join and decrypt messages, so share it only with the person you intend to talk to. Network metadata such as IP addresses may be visible to your internet provider and peer.

Random matching uses a temporary in-memory queue. SPACE does not ask for your gender, intention, or location to connect you. No chat messages are saved to disk or a database.

For a secure browser connection over the internet, this site must be hosted over HTTPS. Connection discovery uses a public STUN service, which can see your IP address. This app does not save chat messages to a database or browser storage.
